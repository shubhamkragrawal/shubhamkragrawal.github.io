# Shubham Kumar Agrawal — Portfolio

Static source for [shubhamkragrawal.github.io](https://shubhamkragrawal.github.io/).

The site presents selected Applied AI, Data Science, ML product, data-platform, and University at Buffalo research work with explicit evaluation boundaries. It shares defensible aggregate research context and results while excluding private code, derived corpora, annotations, reviewer data, internal reports, and unpublished artifacts.

## Local preview

```bash
python3 -m http.server 4173
```

Then open `http://127.0.0.1:4173`.

## Structure

- `index.html` — complete responsive site, styles, and minimal navigation script.
- `assets/` — retained legacy image assets; the current design does not require them.

## Editing rules

- Keep public metrics consistent with the evidence recorded in the project repositories.
- Do not publish private research code, data, annotations, unpublished analyses, or internal artifacts.
- Separate model-level results from system-level outcomes.
- Label local tests, synthetic evaluations, replays, and work-in-progress systems accurately.
